# Simple DirectX 12 3D Car Scene

A native Win32/C++ DirectX 12 scene with an orthographic camera and SimplePaint shading.

Double-click [Run.cmd](Run.cmd) to build and launch the app.

See [Documentation](Documentation/README.md) for setup, controls, implementation details, shader guides, and historical reports.

Platform and GPU constraints for developers and agents are documented in the [platform and GPU policy](Documentation/README.md#platform-and-gpu-policy) and [AGENTS.md](AGENTS.md).
