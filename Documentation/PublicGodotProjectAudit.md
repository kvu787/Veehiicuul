# Public Godot project audit

Inspected September 24, 2026. Enumerated all 41 public repositories owned by kvu787, including the public fork, and inspected their complete default-branch trees (none truncated). Found **13 project.godot files in 9 repositories**. Downloaded and inspected 405 relevant text files, including scenes, resources, C#/GDScript, shaders, project settings, and launch/build scripts.

Scope: current public default-branch snapshots, pinned below by commit. This is not an exhaustive search of deleted files, old commits, other branches, private repositories, or local changes. Imported binary model materials were not exhaustively decoded. “No” means no WorldEnvironment or Environment resource/configuration found in inspected project source. Ordinary mesh colors and UI styling are not individually enumerated; lighting, shadow, shader, antialiasing, renderer and presentation changes are summarized. Explicitly selected defaults are distinguished where useful.

The strongest current Environment matches are the two SimplePaintShaders projects. Both Environment.tres files contain exactly these overrides:

```ini
ambient_light_source = 1
reflected_light_source = 1
```

These enum values disable ambient and reflected light. Environment is a resource, normally attached to WorldEnvironment or Camera3D, rather than a node type itself. See the [Godot Environment documentation](https://docs.godotengine.org/en/stable/classes/class_environment.html#enumerations).
